How This Website Uses My Model

This site does not open the titanic_model.pkl file. It uses the trees that were taken out of it.

1
Trained in Python
titanic_model.pkl

The model learned from 891 passengers using scikit-learn.

2
Trees exported
200 decision trees

The trees were read out of the file as plain numbers.

3
Put inside the page
index.html

The same numbers were written into this page as JavaScript.

4
Runs in your browser
no server needed

When you press Predict, JavaScript runs the 200 trees on your inputs.

NODoes the site open titanic_model.pkl?

No. A .pkl file is a Python file. Browsers cannot read it, and free hosting such as Netlify cannot run Python.

WHERESo where is the model?

Inside this page. The .pkl is only a container, so the 200 trees were taken out and written in JavaScript. Same trees, same numbers.

PROOFIs it really the same model?

Yes. See the Model Inspector below: Python and this page give the same answer for every passenger tested. Over all 891 passengers the difference is smaller than 0.0000001%.

NOTEWhat if the model is retrained?

The page does not update by itself. The new trees must be exported again and put into index.html.

How accurate is it?

On 179 passengers it never saw, it was right 79.3% of the time. On 300 completely new passengers it scored about 76%. The honest range is 76% to 82%.

Why not 90%?

The dataset is small and luck decided who got a lifeboat seat. Scores above 90% on this data usually come from overfitting or data leakage.

Can I trust a single prediction?

No. The model finds patterns in 1912 data. It cannot know what happens to one person. This page is for learning and demonstration only.
